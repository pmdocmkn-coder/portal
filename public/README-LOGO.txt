# Petunjuk Memasang File Video / GIF Logo Intro Asli Anda

Untuk menampilkan file video animasi 3D (.mp4) atau GIF animasi asli Anda di Web Portal MKN:

1. Upload atau letakkan file video/GIF Anda di folder `public/` ini.
2. Beri nama file:
   - `mkn-logo.mp4` (jika format video MP4)
   - ATAU `mkn-logo.gif` (jika format GIF)

Aplikasi akan secara otomatis mendeteksi dan memutar video/GIF asli Anda pada Header, Hero Section, dan Modal 3D Intro Experience!
